# Crossover

A quick family basketball card game, prototype. Play a shot card, the other player stops it with an answer card or it scores, first to 21 wins. A sister game to [Snap Call](https://github.com/noam99moyal/snap-call).

Play it: https://noam99moyal.github.io/crossover/

## Updating

`game.html` is the game itself and `cards/` holds the card images. After changing it, run `python3 build.py ~/Desktop/crossover-netlify.zip` to rebuild `index.html` (this website) and a zip of the whole site for Netlify Drop or itch.io, then commit and push.

`preview/` is the same game at https://noam99moyal.github.io/crossover/preview/, a place to try changes before they go live.
