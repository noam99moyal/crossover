# Crossover

A quick family basketball card game, prototype. Play a shot face up, the defense answers it with a card that stops it or it scores, first to 21 wins. A sister game to [Snap Call](https://github.com/noam99moyal/snap-call).

Play it: https://noam99moyal.github.io/crossover/

## Updating

`game.html` is the game itself. After changing it, run `python3 build.py ~/Desktop/crossover-itch.zip` to rebuild `index.html` (this website) and the zip for itch.io, then commit and push.
